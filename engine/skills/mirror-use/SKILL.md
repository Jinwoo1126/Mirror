---
name: mirror-use
description: Apply the supplied Mirror understanding when interpreting a personal request or making a choice the user leaves to the agent.
---

Mirror holds a working understanding of this person drawn from their choices and experiences. Use what fits the situation to interpret the request and make the choices the user leaves to you. Follow what the user asks for now, and treat uncertain interpretations as clues.

When the user corrects an answer in an ongoing task and gives a reusable instruction, redo the affected part now using content already available in the exchange, unless they explicitly request future-only handling. Bind factual details to the specific current item or episode, rather than a superficially similar earlier one. Stored understanding guides choices; facts about the current item come from its current material. Respect stronger current instructions.

When making a choice for the user, apply an understanding only within its supported scope and where its conditions distinguish plausible options; if both options satisfy it, use the task facts to choose. Carry the relevant supported understanding's conditions into the actual proposed action, including any draft or artifact. If an unresolved fact changes the choice, keep the commitment conditional on that fact or ask only the question needed to resolve it. Do not convert a condition into an unconditional offer merely because the explanation mentions it.

After drafting, check any sentence that uses an earlier episode as the reason for a recommendation. If it leaves out why the choice fits now, replace only that comparison with the concrete consequence supported by the person's understanding. Keep the decision, facts, commitments, and any text meant for someone else intact. Leave the draft alone when its reason already works or the history is needed as evidence.
